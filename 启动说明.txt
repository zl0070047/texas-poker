========================================
  德州扑克春节版 - 如何启动并访问
========================================

若浏览器提示「无法访问此网站」「localhost 拒绝了我们的连接请求」，
说明还没有启动本游戏的服务器，请按下面步骤操作。

----------------------------------------
第一步：安装 Node.js（如果还没装过）
----------------------------------------
1. 打开官网：https://nodejs.org
2. 下载并安装「LTS 推荐版」
3. 安装完成后，关闭并重新打开「终端」

----------------------------------------
第二步：在终端里启动游戏服务器
----------------------------------------
1. 打开「终端」应用（在 Mac 上：应用程序 → 实用工具 → 终端）
2. 复制下面这一整行，粘贴到终端里，按回车：

   cd "/Users/zhulei/Desktop/AI CODE/德普春节版" && npm install && npm start

3. 看到类似「德州扑克春节版 运行在 http://localhost:3000」就表示启动成功
4. 不要关闭这个终端窗口，保持它开着

----------------------------------------
第三步：用浏览器打开游戏
----------------------------------------
在浏览器地址栏输入：

   http://localhost:3000

按回车即可打开游戏。

----------------------------------------
常见问题
----------------------------------------
• 若提示「command not found: node」或「npm 不是内部或外部命令」
  → 说明还没装 Node.js，或安装后没重启终端，请完成第一步。

• 若提示「端口 3000 已被占用」
  → 可先关掉占用 3000 端口的程序，或在终端执行：
    PORT=3001 npm start
    然后用 http://localhost:3001 打开。

• 多人一起玩
  → 保证大家的电脑和你在同一 WiFi（或同一网络），
    你本机用 http://localhost:3000，
    别人用 http://你的电脑IP:3000（例如 http://192.168.1.100:3000）。
    在终端输入 ifconfig 或「系统设置→网络」可查看本机 IP。
