========================================
  GitHub 推送一直提示密码/账号错误 — 解决方法
========================================

原因：GitHub 已经不让用「账号 + 登录密码」推送代码了，
      必须用「个人访问令牌 Token」或 SSH 密钥。下面用 Token 方式。

----------------------------------------
方法：用 Token 当密码（推荐）
----------------------------------------

第一步：在 GitHub 上生成一个 Token
----------------------------------------
1. 浏览器打开 https://github.com 并登录
2. 右上角头像 → 【Settings】
3. 左侧最下面点 【Developer settings】
4. 左侧点 【Personal access tokens】→ 【Tokens (classic)】
5. 点 【Generate new token】→ 【Generate new token (classic)】
6. 若提示输入 GitHub 密码，输入后继续
7. 填写：
   - Note：随便写，例如  push-poker
   - Expiration：选 90 days 或 No expiration（无期限）
   - 在下面勾选：  repo  （把 repo 这一项打勾即可）
8. 拉到最下面点 【Generate token】
9. 页面上会显示一串字符，形如：ghp_xxxxxxxxxxxxxxxxxxxx
   ⚠️ 只显示一次！立刻复制保存到记事本，关掉页面后就看不到了。

第二步：用 Token 推送（把 Token 当密码用）
----------------------------------------
1. 打开「终端」
2. 执行（确保已经添加过 remote，即之前执行过 git remote add origin ...）：

   cd "/Users/zhulei/Desktop/AI CODE/德普春节版"
   git push -u origin main

3. 提示输入时：
   - Username：填你的 **GitHub 用户名**（不是邮箱）
   - Password：粘贴刚才复制的 **Token**（不是你的登录密码！）
   粘贴后终端里可能不显示，正常，直接回车即可。

4. 若还是报错，可以改成「把 Token 写进地址」的方式，这样不用每次输入：

   git remote set-url origin https://你的用户名:你的Token@github.com/你的用户名/仓库名.git

   例如用户名为 zhangsan，仓库名为 texas-poker，Token 为 ghp_abc123xxx，则：

   git remote set-url origin https://zhangsan:ghp_abc123xxx@github.com/zhangsan/texas-poker.git

   然后再执行：

   git push -u origin main

   这时一般不会再问密码。

----------------------------------------
安全提醒
----------------------------------------
- Token 等于密码，不要发给别人、不要贴到网上
- 用「把 Token 写进地址」的方式后，Token 会保存在本机，别人用你电脑时注意账号安全
- 若 Token 泄露，立刻到 GitHub → Settings → Developer settings → Personal access tokens 里删掉该 Token

----------------------------------------
若你用的是「GitHub 桌面版」或其它工具
----------------------------------------
在那些工具里登录时，同样用：
- 用户名：你的 GitHub 用户名
- 密码：填 Token（不是登录密码）
