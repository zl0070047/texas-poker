# 德州扑克 · 春节版

线上多人德州扑克，支持 4–10 人在线、房间邀请、自定义大小盲、每局记录、自定义昵称与文字聊天。

## 功能说明

| 功能 | 说明 |
|------|------|
| **人数设定** | 创建房间时可选 4–10 人，满足人数后房主可开始游戏 |
| **房间邀请** | 创建后获得 6 位房间号，分享给他人即可加入 |
| **大小盲** | 创建房间时设定小盲、大盲金额（整数，≥1） |
| **局局记录** | 每局结束后自动记录赢家、底池、每人盈亏，大厅与游戏内均可查看 |
| **自定义名字** | 在大厅可修改「我的昵称」，游戏中显示该昵称 |
| **文字聊天** | 大厅与游戏内均支持发送文字消息，房间内所有人可见 |

## 使用方法

### 1. 安装与启动

```bash
cd 德普春节版
npm install
npm start
```

浏览器打开：**http://localhost:3000**

### 2. 创建房间

- 选择「创建房间」
- 设置 **玩家人数**（4–10）、**小盲**、**大盲**
- 输入你的昵称（可选）
- 点击「创建房间」，进入大厅并看到 **6 位房间号**

### 3. 邀请他人

- 在大厅点击「复制房间号」，将房间号发给好友
- 好友在首页选「加入房间」，输入 **房间号** 和 **昵称**，点击「加入房间」

### 4. 开始游戏

- 至少 2 人在房间内时，**房主** 可点击「开始游戏」
- 每人初始筹码 1000，发牌后按顺序行动（过牌 / 跟注 / 加注 / 弃牌 / All In）
- 一局结束后会弹出本局结果；房主可点击「下一局」继续

### 5. 查看记录与聊天

- **大厅**：「本房间对局记录」中可看历史局数、赢家、底池
- **游戏内**：下方「本房间对局记录」同样可看；聊天可点击「聊天」展开输入框发送消息

## 参数说明

- **玩家人数**：4–10，创建时固定，不可中途改
- **小盲 / 大盲**：建议大盲 ≥ 小盲，且均为正整数
- **房间号**：6 位数字，由系统随机生成，唯一
- **昵称**：最多 20 个字符，可随时在大厅修改

## 技术说明

- **后端**：Node.js + Express + Socket.io，单机运行即可支持同局域网或本机多窗口联机
- **前端**：纯 HTML/CSS/JS，无需构建
- **部署到线上**：详见 **[DEPLOY.md](DEPLOY.md)**。**中国玩家**建议部署在国内服务器（阿里云/腾讯云），访问更稳定；游戏已做断线重连与中文提示，弱网下会提示房间号便于重进

## 注意事项

- 同一房间内每人昵称可重复，建议自行区分
- 离开页面即视为离开房间；若游戏进行中离开，该玩家视为弃牌
- 对局记录仅保存在当前房间的本次会话中，刷新或关闭房间后不持久化
